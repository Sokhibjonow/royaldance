# 3D Digital Gatefold Invitation

Интерактивное 3D-приглашение на свадьбу: открытка-«гейтфолд» с сургучной печатью и шёлковым бантом
распахивается, а камера влетает внутрь многослойной диорамы с колоннами, фонтаном, голубями и
кружащимися лепестками роз.

**Стек:** Next.js 15 (App Router) · TypeScript · Tailwind CSS 4 · three.js r186 · @react-three/fiber 9 ·
@react-three/drei 10 · @react-three/postprocessing 3 · GSAP 3 · maath · zustand.

## Запуск

```bash
npm install
npm run dev          # http://localhost:3000
npm run build && npm start   # production
```

Текст, имена, дата, адрес, цвета и тайминги — в `lib/invitation.config.ts`.

## Как это устроено

**Свет и материалы.** Тёплый ambient + hemisphere, ключевой `DirectionalLight` с мягкими PCF-тенями
(печать → лента → бумага, створки → внутренний лист), `SpotLight` с текстурой-гобо (тени листвы, медленно
качаются), студийные `Lightformer`-ы в `Environment` для отражений фольги, воска и шёлка, и тёплый
точечный свет, который «заливает» открытку при распахивании створок.

- Бумага: `MeshPhysicalMaterial` с процедурными картами цвета, нормалей (волокна хлопка) и
  roughness/metalness. Орнамент — настоящее тиснение фольгой: в его области metalness 0.85,
  roughness 0.2 и лёгкий продав в рельефе.
- Створки: `ExtrudeGeometry` толщиной 1.8 мм с фаской → тесселяция → группы «лицо / изнанка / торец».
  Изгиб — инъекция в вершинный шейдер (`onBeforeCompile`), продублированная в `customDepthMaterial`,
  поэтому гнётся и тень.
- Сургуч: неровная «налитая» форма, рельеф розы в normal map, `clearcoat 0.3`, `roughness 0.4`,
  немного `transmission` для воскового рассеивания.
- Лента: `sheen 1`, `anisotropy 0.75`; бант распускается деформацией вершин полос
  (каждая точка интерполируется от «завязанного» к «разлетевшемуся» состоянию волной вдоль ленты).

**Таймлайн открытия** (`TIMELINE` в конфиге) повторяет референс: овальная печать отскакивает
к камере и падает вниз-вправо → бант ослабевает, петли расширяются и лента соскальзывает →
створки с туалью из роз открываются на 130° с изгибом бумаги → верхний и нижний фестончатые
клапаны откидываются → внутренний лист растворяется, камера въезжает внутрь.

**Сцены:** Бисмиллях между двумя колоннами в розах (гирлянда, голуби, букеты) → лёгкое
затемнение → страница в акварельной рамке с колонной слева: «С любовью и благодарностью»,
приглашение → колонна сменяется фонтаном, рамка «расцветает»: серебряная монограмма, дата,
имена, дуа → время и место (тап по блоку открывает карту) и «Ваше присутствие…».
Страницы листаются сами (`AUTOPLAY`), можно листать свайпом/колесом/стрелками.
Текст набирается на canvas (браузер правильно соединяет арабские буквы) и проявляется
из размытия шейдером.

**Звук:** музыка из `public/audio/music.mp3`; шелест бумаги, шорох ленты и «щелчок» воска
синтезируются WebAudio, если не положить свои записи. Вибрация (`navigator.vibrate`) на нажатие.

**Гироскоп:** на iOS разрешение запрашивается при нажатии на печать.

## Свои иллюстрации

Сайт полностью работает без картинок — всё построено процедурно. Если у вас есть нарисованные
слои, нарежьте их в PNG с прозрачным фоном и положите в `public/textures/` с именами из
`public/textures/README.md` (створки, печать, внутренний лист, колонны, голубь — тело и крыло
отдельно, фонтан). Они встанут на свои глубины автоматически. Production-сборка (`next build`)
проверяет файлы при сборке — после добавления PNG пересоберите проект.

## Производительность

`PerformanceMonitor` снижает DPR и отключает MSAA при просадке FPS; на тач-устройствах меньше
лепестков и мягче постобработка. Отладка в headless-браузере: `/?capture&timescale=0.1`
(отключает lag smoothing у GSAP и замедляет таймлайн).
