# Звук

- `music.mp3` — фоновая музыка: оригинальный романтический фортепианный вальс со струнными,
  сгенерированный скриптом `scripts/compose-music.py` (без авторских прав, зацикливается без шва).
  Чтобы поставить свою песню, просто замените файл (MP3, тот же путь) и пересоберите проект.
  Музыка стартует после нажатия на печать и плавно нарастает.
- `paper.mp3` — шелест плотной бумаги (необязательно — иначе синтезируется WebAudio).
- `ribbon.mp3` — шорох шёлковой ленты (необязательно — иначе синтезируется WebAudio).
