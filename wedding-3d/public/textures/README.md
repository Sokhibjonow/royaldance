# Нарисованные слои (необязательно)

Положите сюда PNG с прозрачным фоном — они автоматически заменят процедурные 3D-слои
(после `npm run build` или сразу в `npm run dev`). Имена файлов задаются в
`lib/invitation.config.ts → TEXTURES`.

| Файл               | Что это                                  | Слой / глубина     | Рекомендуемый размер |
|--------------------|------------------------------------------|--------------------|----------------------|
| `flap-left.png`    | рисунок левой створки (поверх бумаги)    | створка, Z = 0     | 512 × 1464           |
| `flap-right.png`   | рисунок правой створки                   | створка, Z = 0     | 512 × 1464           |
| `seal.png`         | цвет/рисунок сургучной печати (круг)     | печать             | 512 × 512            |
| `backdrop.png`     | внутренний лист приглашения              | диорама Z = 0      | 1024 × 1464          |
| `column-left.png`  | левая колонна                            | Z = +0.5           | ~300 × 2000          |
| `column-right.png` | правая колонна                           | Z = +0.5           | ~300 × 2000          |
| `dove-body.png`    | тело голубя (головой вправо)             | Z = +0.7           | 512 × 256            |
| `dove-wing.png`    | крыло, плечо — по центру нижнего края    | Z = +0.7           | 512 × 256            |
| `fountain.png`     | мраморный фонтан (струи остаются 3D)     | Z = +0.5           | ~1000 × 900          |

Створки, печать и внутренний лист используют PNG как *цветовой слой* — рельеф
хлопковой бумаги, толщина, фестончатый край и тиснение фольгой остаются настоящими 3D.
